The **kirby-fitzpatrick-gricean-bridge-connector** skill transforms cognitive writing science into deterministic rules for AI coding assistants, code reviews, and system documentation.

## Core Patterns

- **Gricean Bridge Connector**: Gricean Bridge Connectors: bind independent clauses using explicit conjunctions ('because', 'therefore', 'in contrast') rather than ambiguous juxtaposed sentences.
- **Practical Application**: Bug diagnosis post-mortems and compiler error message diagnostics.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
